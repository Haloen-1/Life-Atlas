# Life Atlas

- Every new user-facing feature must also be visible and configurable in Workspace. Add a clearly labeled control for its behavior, persist the user's choice, and test that it affects the feature after a reload.
- Preserve data-loss safeguards: Workspace may offer stronger confirmation, not a bypass.
- After requested changes pass verification, commit and push the app changes to origin. Never include private browser data or JSON backups, and never modify the personal installation directly.
